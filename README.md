# Null Browser

Null Browser is an open-source Firefox/Gecko-derived browser project focused on privacy, security, and a highly transparent user experience.

## Product direction

- Windows first
- Android later through GeckoView
- Private Mode is the default
- Ghost Mode is the optional Tor mode
- No separate Secure Mode
- IPv6 must not bypass the active privacy/network policy
- Real browser geolocation is not exposed by default
- Privacy location can be user-configured
- English-first interface
- Privacy-oriented locale/timezone policy with consistency checks
- No product telemetry by default
- No browsing history by default
- No password saving by default
- Strong tracker/ad blocking
- DNS and WebRTC protection
- Fingerprint resistance
- Local-only Live Control Panel
- Evidence-based privacy status instead of fake "100% anonymity" scores
