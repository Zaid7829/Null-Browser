# NULL BROWSER — MASTER RULES

1. Privacy is enabled by default.
2. Security takes priority over feature count.
3. Never claim perfect anonymity or perfect security.
4. Never fabricate APIs, source paths, preferences, or test results.
5. No product telemetry or advertising analytics by default.
6. No unnecessary persistent identifiers.
7. IPv6 must not bypass the active privacy/network policy.
8. Real device geolocation must not be exposed by default.
9. Default browsing history is disabled.
10. Password storage is disabled by default.
11. WebRTC must not expose protected network addresses.
12. DNS must follow the configured privacy policy.
13. Ghost Mode uses Tor.
14. Ghost Mode is isolated from Private Mode.
15. Ghost Mode uses a temporary isolated profile/session.
16. Do not implement custom cryptography.
17. Do not implement a custom Tor/anonymity protocol.
18. Do not silently add third-party network services.
19. Every security-sensitive feature requires tests.
20. Every privacy feature requires documented threat analysis.
21. Upstream Firefox security updates are mandatory for release maintenance.
22. The Control Panel is local browser UI and must not leak its private state to websites.
23. Do not create privacy features that accidentally increase fingerprint uniqueness.
24. Prefer internal consistency over arbitrary randomization.
25. Prefer a smaller attack surface over decorative functionality.
26. Every important privacy status shown to the user must correspond to real browser state.
