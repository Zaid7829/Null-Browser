# Ghost Mode

Ghost Mode is the optional Tor-based high-privacy mode.

Requirements:
- Tor routing
- onion-service support
- isolated temporary browser profile
- no ordinary storage sharing
- no identity sharing with Private Mode
- stronger fingerprint protections
- stricter permissions
- restricted extensions by default
- privacy-focused diagnostics
- session/identity reset capability

Do not implement Tor itself.
Use mature Tor software/components.
