# Privacy Model

## Private Mode

Default protections should minimize:
- tracking
- advertising requests
- persistent cookies
- site storage
- history
- password storage
- unnecessary permissions
- fingerprint exposure
- telemetry

## Ghost Mode

Prioritize anonymity over broad website compatibility.

## Design principle

Do not "randomize everything".
Random values can make a browser more unique.

Use privacy values that are:
- limited
- coherent
- stable for the required scope
- hard to correlate unnecessarily
