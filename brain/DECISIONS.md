# Architecture Decisions

- Private Mode is the default.
- There is no separate Secure Mode.
- Ghost Mode is Tor-based.
- IPv6 must not bypass the privacy network policy.
- Real device geolocation is blocked by default.
- Initial privacy location is London, UK.
- English is the default interface language.
- The Control Panel is a first-class subsystem.
- Privacy status must be based on real state, not decorative percentages.
- Locale/timezone randomization must not be allowed to create stronger fingerprints.
