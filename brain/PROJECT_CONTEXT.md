# Null Browser — Project Context

## Identity

Name: Null Browser

Technology foundation:
- Mozilla Firefox / Gecko
- GeckoView for Android in a later phase

## Product goal

Build a fast, polished, privacy/security-oriented browser that makes protective behavior understandable through a live, local Control Panel.

## Modes

### Private Mode
Default everyday mode.

### Ghost Mode
Optional high-privacy mode using Tor. Ghost Mode is isolated from ordinary browsing.

There is no separate Secure Mode.

## Core idea

Null should expose useful, truthful visibility into:
- network protection
- DNS state
- IPv6 state
- WebRTC state
- trackers and ads blocked
- storage/cookie isolation
- fingerprint defenses
- location policy
- permissions
- Tor state
- live privacy events

## Product standard

The browser should feel like a serious security product rather than an AI-generated demo.
