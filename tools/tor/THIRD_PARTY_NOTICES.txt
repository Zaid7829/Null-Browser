# THIRD-PARTY SOFTWARE NOTICES AND INFORMATION FOR BUNDLED TOR RUNTIME

Null Browser bundles an official standalone distribution of the Tor daemon for use in Ghost Mode.
Source: The Tor Project (https://www.torproject.org/)
Release: Tor Expert Bundle windows-x86_64 15.0.23 (Tor 0.4.9.12)
Official Upstream Archive: https://dist.torproject.org/torbrowser/15.0.23/tor-expert-bundle-windows-x86_64-15.0.23.tar.gz
Upstream Source Repository: https://gitlab.torproject.org/tpo/core/tor (tag tor-0.4.9.12)

The redistributed tor.exe reports GPLv3 coverage for this official build; the Tor source tree contains components under multiple applicable licenses. See the accompanying upstream notices and corresponding-source information.

Null Browser does not modify the Tor source code or binary. The Tor executable is invoked solely
as an independent subprocess via standard inter-process communication pipes (mere aggregation).

===============================================================================
1. REDISTRIBUTED BINARY BUILD (tor.exe)
===============================================================================
Official Tor Expert Bundle binaries compiled by The Tor Project enable the Onion Service
Proof-of-Work (PoW) DoS defense mechanism (using Equi-X and HashX). Consequently, official
Tor Project binaries report coverage under the GNU General Public License v3 (GPLv3).
The full GPLv3 license is available at: https://www.gnu.org/licenses/gpl-3.0.en.html

Redistribution & Aggregation Terms:
Null Browser bundles the unmodified Tor executable as a separate standalone program.
Under GPLv3 Section 5 ("mere aggregation"), inclusion of a GPL-covered program in an aggregate
with independent works does not cause GPLv3 to apply to the other parts of the aggregate.
In accordance with GPLv3 Section 6, the complete corresponding source code for the official
Tor build is publicly available from The Tor Project at:
- https://dist.torproject.org/torbrowser/15.0.23/
- https://gitlab.torproject.org/tpo/core/tor (tag tor-0.4.9.12)
